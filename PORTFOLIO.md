## Selected work

### [Meu Ritmo](https://meuritmo.net) — Web SaaS

A personal organization and financial management application for individuals and shared spaces.

I worked across the product, from interface design and application logic to authentication, database integration, payments and deployment.

- Daily planning, calendar, routines, reminders and personal finance tools.
- Email authentication, account management and access controls.
- Paid plans and Pix checkout through Asaas, with payment confirmation and subscription access.
- Administrative tools, promotional coupons and data export.
- Cloudflare Workers deployment with D1 storage and Supabase authentication.

**Stack:** TypeScript, React, Next.js, Tailwind CSS, Node.js, Cloudflare Workers, D1, Supabase.

[Visit the product](https://meuritmo.net) · [Source code](https://github.com/JustJao1/meu-ritmo)

### [Meu Ritmo App](https://github.com/JustJao1/meu-ritmo-app) — Android companion

An Android application that extends Meu Ritmo with access to the online platform and a separate offline module for device alarms and local notes.

- Android APK distribution and versioned releases.
- Native device alarms, local storage and an update policy.
- Integration with the existing web product.

**Stack:** Android, JavaScript, Gradle.

[View application](https://meuritmo.net/app) · [Source code](https://github.com/JustJao1/meu-ritmo-app) · [APK releases](https://github.com/JustJao1/meu-ritmo-app/releases)

### [Imóvel em Dia](https://imovel-em-dia-portfolio.vercel.app) — Property operations platform

A Brazilian Portuguese property-management application that connects inventory, maintenance, purchasing, reservations and financial records.

- Property-level dashboards and automated inventory shortage tracking.
- Reservation conflict prevention and transactional receivable settlement.
- Organization-scoped SQLite data, session authentication and audit history.
- 15 automated backend tests covering business rules, HTTP APIs and mocked integrations.

**Stack:** Python, SQLite, JavaScript, HTML, CSS.

[Interactive demo](https://imovel-em-dia-portfolio.vercel.app) · The public demo uses fictional browser-local data; the Python backend runs locally. Live payments and external AI are not enabled. A standalone source repository is pending publication.
